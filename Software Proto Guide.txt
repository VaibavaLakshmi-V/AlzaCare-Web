Extra Helpful Info.

The IP can change, especially if you switch Wi-Fi or use a hotspot. To get the current one:

Open Command Prompt and type ipconfig.
Find IPv4 Address under your active Wi-Fi adapter (something like 192.168.x.x).
Use that number in the phone link.

Phone checklist

The phone must be on the same Wi-Fi as the laptop. College Wi-Fi often blocks this, so at the review, turn on your phone’s hotspot, connect the laptop to it, run ipconfig again, and use the new IP.
If the page won’t load, Windows Firewall may be blocking it. Allow Node and Python when Windows asks.

Which device does what in the demo

Laptop: open http://localhost:5173/station. Use localhost here, not the IP, because browsers only allow webcam access on localhost or HTTPS.
Phone: open the caregiver app (the link above) and log in with caregiver / alza123.
